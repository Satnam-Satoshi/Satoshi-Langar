- Treasury Intelligence
- Mobile navigation
- Accessibility
- Performance
- Broken links
- Factual claims
- LIVE / BUILDING / RESEARCH / FUTURE maturity labels
- Human governance language
- Financial/legal disclaimers
- GitHub contribution paths
- Domain/runtime readiness

## Deferred until after Public Alpha

- Supabase and live Treasury backends
- Advanced agents
- Crypto Kitty implementation
- Token architecture
- Ordinal automation
- Repository migration
- Expanded governance volumes
- Legal entity formation work that does not directly affect truthful public claims
