# Private coverage compiler (nonproduction)

`node --test scripts/test-cloud-newsroom-v2-coverage.mjs`

`compileCoverage(input)` is a deterministic, effect-free projection. It imports only node:crypto, reads/writes nothing, makes no network calls and cannot publish. Clock is explicit. It returns every declared source/desk and every trusted-outline story with every required platform; batch size never truncates inventory. Output is deeply frozen. `publishAllowed` and `operational` are always false. Reports must stay private because their gap/evidence identifiers are not public editorial copy.

## Inputs and trust boundary

- `registry`, `expectedRegistryDigest`: accepts the **existing**, unchanged cloud-newsroom-v2 registry and scanner SHA-256(JSON.stringify(registry)) convention. Desk labels derive directly from its sources and retain spelling, including spaces; no parallel source registry is maintained. `maxCheckAgeHours` is required explicitly. Also accepts a small normalized test contract with `desks:[{id}]`, `sources:[{id,deskId,maxAgeMs}]`, pinned via canonical JSON digest.
- `scan`: existing `read-only-source-scan` envelope / observations (raw registry mode), or `{registryDigest,sources:[{id,attemptedAt,outcome,contentDigest,retrievalExpiresAt}]}`. Missing observations remain not-attempted. Unknown statuses/IDs and duplicate observations fail. Unavailable, redirects and unsupported-media retain original retrievalStatus and any reason; none is treated as no news.
- `extractions:{registryDigest,sources:[...]}`: only **independently verified** records. Each record contains `id,verification:'independently-verified',parserId,evidenceLocator,observedBytes,contentDigest,retrievedAt,observedAt,verifiedAt,expiresAt,material,materialDigest`, optionally `previousMaterialDigest`. UTF-8 observedBytes are hashed and bound to scan hash. `material` is a nonempty JSON object; its canonical digest is checked. Prior digest must come from the trusted previous verified record, not a source response. `observedAt` is source-effective factual observation time, not simply the fetch time. Freshness expires at the earliest of observedAt + registry max age, scanner retrievalExpiresAt, and independently supplied extraction-policy expiresAt. At the exact deadline the record is stale (strict now < expiry). Scanner expiry is mandatory for retrieved observations; policy expiry is mandatory for verified records. These expiry timestamps may be in the future, but actual observation, retrieval, and verification dates may not. Missing expiry fails closed. Policy expiresAt must be supplied by the trusted verification adapter, never inferred from a source response or the scanner cap. Output preserves all three effective/explicit deadlines. The caller must independently establish the parser/evidence/material semantic binding: a string flag and digest alone cannot prove claims. Do not pass candidate-for-review extraction-stage records as verified records. They remain needs-extraction here until independent review.
- `outline:{registryDigest,platforms,stories:[{id,deskId,storyDigest,sourceIds,editorialState:'pending'|'prepared'}]}`, plus `expectedOutlineDigest` (canonical SHA). This is a trusted adapter projection of the canonical reader outline, with explicit source/desk bindings and required marketing platforms. The raw reader outline lacks these bindings; this compiler does not fabricate them. A prepared story with incomplete/stale sources is reported pending.
- `marketing:{registryDigest,batches:[{stories:[{id,platform,storyDigest,assetState:'pending'|'prepared',assetDigest,postState:'pending'|'queued'|'published',receiptId,reportedAt}]}]}`. Records must be tied to exact trusted story digests. Prepared assets require digest; queued/published claims require asset and receipt ID. This is a report-only adapter, not the live backlog store. A summary `campaignComplete:true` does NOT substitute for per-story/platform evidence. All completed states are explicitly suffixed `-reported`; `publicationVerified:false` remains explicit. Duplicate pairs across batches fail (snapshot adapter must reconcile event history before calling). Missing pairs remain pending.
- `now`: strict millisecond ISO UTC timestamp. All observation/report/verification times are checked against this clock. Deterministic retention/expiry decisions require a trusted clock.

## Gaps and integration limits

Existing extraction stage currently yields candidates-for-review, not independently verified extraction records. Use an empty verified-record list until review succeeds. This compiler does not claim all ecosystem sources are implemented and does not infer complete ecosystem coverage from the finite registry. Its readiness is per-declared desk only. No schedules, runtime, publishing permission, hosting, Buffer dispatch, ledger or production wiring are changed. Raw bytes stay out of output. Material change is canonical extracted material vs trusted prior material, not retrieved-page hash changes. First observations are distinct from proven change.

Adapter integration and independent review are still required before incorporation into the producer. The module is source-only nonproduction integration. No producer automation or publishing runtime is activated.
