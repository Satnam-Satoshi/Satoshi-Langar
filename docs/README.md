## Technical and historical reference

[Architecture](../ARCHITECTURE.md) describes current and proposed layers. [ADR template](ADR-TEMPLATE.md) provides a format for decisions. [Publication provenance](PUBLICATION-PROVENANCE.md) describes research evidence design.

Older materials are preserved for context, not treated as a current deployment inventory:

- `EXECUTIVE-BUILD-REPORT-2026-08-06*`, `PUBLIC-ALPHA-RELEASE-CANDIDATE.md`, screenshots and Lighthouse reports are dated build evidence.
- `AGENT-ARCHITECTURE.md`, `REPORT-SPEC.md`, `COMMERCIAL-MODEL.md` and `DEPLOYMENT-STACK.md` describe earlier research-product designs. They do not establish active subscriptions, payment services, agent permissions or a live database.
- `ADR/` preserves existing architecture decisions. The new documentation does not adopt a second constitution or silently approve old proposals.

When documents disagree about what is live, use [STATUS.md](STATUS.md), dated evidence and the current source/PR. Open a correction with links to both records. Revisit status after each accepted release or material change.
