# Program discovery and explanation — October 5, 2026

The founder could not find dedicated Langar/Kalakar.x pages or Litecoin Register from the mission page. Existing routes are retained and now begin with illustrated explanations before operational detail and the contribution toolkit.

A shared `ProjectQuickLinks` navigation is visible below both community and magazine headers at desktop and mobile sizes. It links directly to `/langar/`, `/kalakar/` and the external `https://litecoinregister.com/?c=table`. The magazine uses its own shell and hides the community header; the shared shortcut component is deliberately rendered inside both headers so exactly one visible set remains. The publication footer also includes these destinations.

Langar explains the tradition, the proposed human/AI workflow, privacy-preserving service records, optional future support and a guest planning path. Kalakar.x explains artist control, creative briefs, a proposed direct Bitcoin/Lightning invoice workflow and voluntary connections to Langar. Original planning templates, query-selected guest paths and public-proposal boundaries remain.

Existing original conceptual images are reused from the special-edition art library. They are labeled as concepts, not evidence of operating kitchens, artists or commissions. Pilot, grant, marketplace and payment features remain inactive. No authentication, wallet, domain, donation destination or daily source-method changes are made. The founder retains governance and financial authority.

Background sources: https://www.sikhcoalition.org/about-sikhs/faq/ and https://docs.btcpayserver.org/Invoices/ (reviewed October 5, 2026). No new financial advice is introduced.
