## Agent charter and audit

- Mission: create four reviewable editorial images for the founder-requested 84-page Litecoin special edition.
- Human owner: Satnam Satoshi founder. Humans retain publication, governance and financial authority.
- Responsibilities: composition, visual consistency, accessible captions, source provenance and output inspection.
- Knowledge sources: the founder’s creative direction and the image-generation skill. Artwork makes no factual claim about events or project delivery.
- Permissions: generate original images and save project assets plus this record. No accounts, credentials, deployment, funds or application-code changes.
- Escalation and emergency stop: stop on an unsafe, unreviewable or materially misleading output; notify the lead agent.
- Memory scope: this special-edition project only; no private inputs or personal data used.
- Tool mode: built-in `image_gen.imagegen`, generate mode, four sequential calls, no reference images, `transparent_background: false`. No CLI fallback.
- Post-processing: RGB conversion and progressive JPEG encoding at quality 90 with Pillow; no cropping, resizing, redrawing or compositing. Original PNGs retained at the image tool’s generated-images destination.
- Visual review: all four generated outputs were inspected. Checked composition, absence of generated words and logos, no identifiable real people, palette consistency, conceptual rather than documentary appearance, and suitability for text placed separately in the page layout.
