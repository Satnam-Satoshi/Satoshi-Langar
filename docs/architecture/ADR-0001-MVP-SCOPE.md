## Problem

The institution has multiple possible initiatives, but a credible first release requires a narrow, coherent boundary.

## Options considered

1. Release all proposed SSCOS products together.
2. Release one product only.
3. Release a shared gateway and the three explicitly authorized public programs.

## Decision

Choose option 3. The MVP contains only Satnam.x, Treasury Intelligence, Lunch Time Conversations, and Satoshi Langar MVP. Everything else is Phase 2. No production implementation is authorized by this ADR.

## Reasoning

The four surfaces form a coherent public-interest release while limiting technical, content, security, and operational complexity.

## Benefits

Clear public narrative, shared infrastructure, measurable adoption, and bounded release risk.

## Tradeoffs

Accounts, payments, autonomous services, advanced analytics, and other programs are deferred.
