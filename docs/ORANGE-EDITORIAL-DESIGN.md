# Orange editorial design · November 2026

## Approved direction

Satnam Satoshi is the welcoming community front door. LTC Magazine is a distinct editorial product, not a duplicate of the community page. Shared Bitcoin orange, ink and the original brand assets connect them. Strong sans-serif display type carries the main headlines; readable editorial text and disciplined rules support longer reading.

The visible path is Learn → Read → Verify → Contribute. Litecoin Register has a primary-navigation link and a dedicated evidence panel on each front door. It is labeled an independent external resource. The 84 million / 21 million figures describe protocol supply limits, never live holdings or a treasury balance.

## Cover system and marketing

`LtcEditionCover` is the single headline-bearing jacket for each dated issue. It reads title, subtitle, artwork and date from the saved edition. The homepage, archive and reader use this same component. Artwork is conceptual and never documentary evidence.

- Maintain the LTC masthead, prominent headline, restrained supporting line and issue date.
- Keep headline contrast against a shaded artwork field and allow long headlines to wrap.
- Use the entire portrait cover in marketing; do not replace it with a generic landscape card.
- Use topic-appropriate original artwork for new issues. Do not overwrite historical dated artwork or invent new claims during a visual refresh.
- Export a cover from the verified static build, check the actual pixels at phone size, and preserve a text caption with the issue link and source context.
- Marketing publication remains a separate authorized operation. This branch does not change Buffer, schedules, credentials, or social ledgers.
