# Immutable desk revision preparation

`planDeskRevisionAppend({now,registry,trustedRegistrySha256,prior,trustedPriorSha256,proposed,sourcePolicies,evidenceInventory})` is a pure, nonpublishing proposal. Registry schemaVersion1/generationcloud-newsroom-v2 and its independently supplied canonical digest are required. Exact existing desk labels (including spaces/&), not guessed slugs, are preserved. Prior is explicit (no implicit bootstrap) and must be independently retained history; its independently supplied canonical SHA256 is mandatory, including an empty initial module. Do not derive this trust argument from an untrusted proposed replacement. History retains every prior record and never rechecks its age as new evidence. Same-ID identical data is a no-op with null expiry and no refreshed coverage; divergence rejects. Preparation timestamps cannot go backwards. Per-desk revisions are contiguous and bind preceding canonical record hash via parentSha256.

Module `{schemaVersion:1,records:[...]}`. Exact record keys: id,deskId,revision,parentSha256,preparedAt,kind,asOf,payload,evidence. Kind current/historical; preparation is not publication. Evidence items are exact `{sourceId,url,sha256,materialDigest,retrievedAt,evidenceLocator,parserId,parserVersion,publisherId}`. Locator is a bounded evidence-relative path without traversal. Parser/version/publisher must match independent policy and inventory; locator must match inventory. URLs must exactly match the independently provided source registry's source ID and desk. Payload is bounded canonical inert JSON, preserving null/zero, units and limitations without coercion. No verified flag is recognized. This module does not parse raw JSON bytes; a future byte loader must reject duplicate JSON keys before parsing. Never inject payload strings as HTML.

Independent inventory entries: `{sourceId,url,bytes:Uint8Array,sha256,materialDigest,retrievedAt,asOf,kind,metricKind,reviewedDataSha256,evidenceLocator,parserId,parserVersion,publisherId}`. Hashes are computed from actual bytes; canonical payload hash must match an independently reviewed extraction digest. This is an explicit external semantic-review dependency, not a claim that raw-byte hash equality proves a fact. All clocks must match immutable record evidence; a new retrieval of identical source text cannot silently refresh the old record. Inventory source bytes remain private and are never included in output. The adapter must also bind materialDigest to its independently reviewed extraction pipeline. It must not manufacture reviewedDataSha256 from an unreviewed candidate.

Policies keyed exact sourceId: `{sourceId,url,kind,metricKind,maxRetrievalAgeSeconds,maxEffectiveAgeSeconds,expiresAt,parserId,parserVersion,publisherId}`. Metric type is independently bound in inventory. Pinned ceilings from existing source-policy module: venue quote7200, Morpho900, chain1200, primary86400 seconds. Both retrieval and current effective caps cannot exceed them. Historical asOf may retain valid YYYY-MM-DD precision; it is never rewritten to a fabricated midnight timestamp. Current values require exact UTC instants. Historical explicitly requires null effective cap but still fresh source retrieval for a NEW record. Earliest source/policy deadline and five-minute proposal bound control expiry. No expired proposal authorizes a write; this module has no writer.

Bounds: 200 sources/inventory entries; 2MiB per private source/16MiB total; 50 proposals; 500 total retained records/4MiB public module; 128KiB per record; bounded depth/arrays/text. Excess holds, never trims history. Every registered source/desk appears in coverage, including unhandled gaps. Registry URLs alone do not prove publisher identity; the coordinator must supply reviewed registry/policy/inventory, not model-authored trust.

`deskRevisionViewPreparation` maps records to existing prepared cards with explicit separately supplied desk routes. It never adds publication evidence. The coverage worker separately binds extraction material digest and source observations; reachability is not rendering or publication proof. No CI, admission scope, production or old history mutation is authorized by a proposal.

Output moduleJson is canonical serialized JSON and moduleSha256 hashes its UTF8 bytes. Preservation means identical canonical records, not arbitrary original whitespace/key order. Durable storage/CAS and independently authenticated prior inventory are not implemented by this pure preparation module.
