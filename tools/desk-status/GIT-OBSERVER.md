# Complete Git observation and separate bootstrap preparation

`observeDeskGitObjects({repoRoot,sourceCommit,treeGitSha})` reads pinned local Git objects through fixed /usr/bin/git, never the working tree/index. Both SHA1 identities must be independently supplied. A clean bounded environment ignores inherited Git overrides, global/system config, replacement refs, optional locks and lazy fetching; command options disable hooks/fsmonitor and all network protocols. No shell interpolation, checkout or writes. SHA256 object-format repositories are explicitly unsupported.

The observer verifies raw commit SHA1 and its root-tree header; discovers object IDs with ls-tree, bounds sizes before batch cat-file, recomputes raw tree/blob OIDs, and recursively parses the verified raw root tree to prove every file is covered. Discovery output alone is not trusted for completeness. Strict UTF8 applies to paths, never binary data. Symlinks/submodules/unsafe paths fail. No source-file filter. Bounds: 20000 discovered entries,10000 files,32MiB/object,96MiB unique object bytes and expanded file bytes,128MiB process output,depth32,30seconds/command. Every emitted file has exact SHA256/byte count/mode. moduleBytes is returned only for the fixed desk JSON; full private source bytes are not emitted.

Return `{observation:{sourceCommit,treeGitSha,entries},inventorySha256,moduleBytes,verification,effects:[]}` feeds data admission after independent trust pin checks. It does not verify editorial facts, establish owner approval, authorize source changes or fence another writer.

`prepareDeskBootstrap({now,observation,reviewedEmptyModuleBytes,independentReview})` is DISTINCT from append admission. It requires exact canonical empty JSON `{records:[],schemaVersion:1}` bytes (canonical keys in actual bytes), an independently supplied review binding commit/tree/inventory/module hashes and an unexpired preparation-only scope. Existing module or path conflicts reject. It returns the exact new file and a proposed complete candidate inventory retaining all prior files. It creates no Git tree/commit/ref/file. A caller-supplied review record is not authenticated user/security approval. Result always effects:[],writeAuthorized:false,publicationAuthorized:false; actual source bootstrap needs separate review and authorized execution.
