# Actual local draft artifacts, not publication

`renderer/render.py` uses ReportLab and Pillow to produce actual PDF, inert HTML, original PNG cover/promo and a hash/byte manifest. It has no network, model, token or cloud upload. Every artifact visibly says DRAFT - NOT FOR PUBLICATION; there is no approved/public mode. Input is bounded plain-text structured draft data; this renderer does not authenticate evidence, approve facts or infer their freshness. The original dates, limitations and explicit gaps remain visible. The geometric illustration is labeled an editorial process illustration, not market data or completed approval.

`src/local-render-dispatcher.mjs` defaults off. When explicitly enabled for local preparation it invokes only fixed `/usr/bin/python3 -I -B` and the packaged renderer, under a bounded timeout/output. Work occurs in a new private temporary child of the explicit real directory. It verifies actual four output files against the resulting manifest, PDF signature and PNG sizes. It never claims visual QA from those byte checks, uploads, publishes, retries or overwrites a prior artifact folder. Partial work on errors is retained for inspection. No publication-effect journal is needed for these local drafts; actual remote storage/publishing still requires its own durable intent/readback.

Dependencies: reviewed Python, ReportLab, Pillow, DejaVu fonts. Tests additionally use pypdf; visual QA uses Poppler. The source CI installs only official distro packages in its ephemeral test worker. No desktop install or cloud service provisioning occurs. The OCI image is still not built: a reviewed official base digest and exact dependency recipe/runtime identity must be finalized and tested before deployment. Manifest records actual Python/ReportLab/Pillow, font and renderer hashes; deterministic bytes are tested only within the same environment, not assumed across versions.
