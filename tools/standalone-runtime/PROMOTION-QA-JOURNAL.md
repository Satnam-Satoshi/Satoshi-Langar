# Dormant stage-aware promotion QA journal v2

New paths only: `newsroomPrivatePromotionQaV2/inventory` and `newsroomPrivatePromotionQaRecordsV2/<key>`. Root schema is `{schemaVersion:2,generation:'standalone-promotion-qa-v2',initialized:true,revision:1,claims:{}}` for a genuine independently initialized new inventory. No runtime bootstrap, migration, deletion or reset. Existing v1 proofs/rows remain untouched. Limit100 stage records; migration must be explicitly planned before exhaustion.

Factory `createFirestorePromotionQaJournal` accepts fixed SDK project/database, claim owner/fence, clock, `mutationEnabled:false` default and exact identity:
`promotionKey, attemptingRecordSha256, stage, planSha256, sourceCommit, manifestSha256, candidateDeploymentId, projectId, teamId, expectedBaselineDeploymentId, domains, finalPreviewProofSha256`.
Stage is `final-preview` (final hash null) or `public-readback` (final hash required). Domains are the fixed canonical pair. The storage key hashes only promotionKey+stage; differing identity cannot fork a replacement record for that attempt/stage.

`read()` returns null only for a genuinely absent unindexed row, or `{version:1|2,proofJson,receipt}`. `freeze(proofJson)` creates immutable version1. `archive(proofJson,receipt)` advances exact bytes to version2; receipt exact `{fileId,version,sha256,bytes}` must bind those bytes. Receipt must come from the concrete archive helper's verified result; this store does NOT independently call Drive or authenticate a caller-supplied receipt. Same bytes/receipt are idempotent; later proof/receipt replacement is never allowed, including after expiry. Unknown transaction outcomes latch writes; read remains available and restart must inspect canonical state before attempting further effects.

Final-preview freeze requires unexpired preview QA; archival can finish after expiry, but cannot authorize promotion. Public-readback requires exact successful observations for both domains, all four identical artifact identities, source/plan/deployment/baseline bindings, and the same intent's archived final-preview record/hash. Historical public proof may retain fresh:false or an expired source deadline. It is never relabeled fresh. Public version2 is durable completion evidence only when the trusted orchestrator actually produced the proof and the concrete archive helper verified its receipt. Marker/link checks still do not establish semantic truth, complete rendered-body equivalence or visual approval.

`observeControl()` performs a fresh read-only existing inventory+control transaction and returns exact owner/fence/checkedAt/expiresAt after current lease/stop validation. Promotion must call it after final archival, then recheck approval/time synchronously before POST. This remains cooperative, not provider-enforced fencing.

Writes read root/row/control before mutation, maintain index version/hash, reject lost indexed rows, orphan rows and mismatched identity, and use current owner/fence/live lease. The public stage also reads and verifies its exact archived final-stage row in the transaction. Control decoding reuses the actual FirestoreState512KiB canonical codec; serialized proof is independently bounded128KiB, not routed through a small identity string limit. Read-only historical records remain available after lease/source expiry; writes require a live lease. No credentials, live SDK/provider tests or resource setup are performed by this module's synthetic suite.
