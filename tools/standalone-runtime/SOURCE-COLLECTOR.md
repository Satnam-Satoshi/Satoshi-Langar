# Dormant direct source collector

`createSourceCollector({networkEnabled:false, transport, clock}).collect({previousCoreRelease:null})` preserves all 43 registered source outcomes, raw-byte hashes and original retrieval clocks. No request occurs by default. Enablement must be an independently reviewed deployment choice. The native transport is `createPublicHttpsTransport()`, not an ambient fetch or connector. It has fixed registry URLs, HTTPS certificate verification, public IPv4 DNS pinning, no redirects, no proxy configuration, no credentials/cookies, a 15-second DNS/request/stream deadline, 2 MB/source and 16 MB/run accepted evidence bounds. IPv6 and special-use IPv4 destinations are deliberately unavailable. Registry changes require source review. Injected test transports are trusted adapters, not authenticated evidence by themselves. No automatic retry.

Core JSON extracts exact source fields with JSON-pointer provenance. Initial observation is unknown baseline, not new news; original release publication dates remain distinct from retrieval. Source prose, including release markup, is inert untrusted text and must never be rendered as HTML or followed as instructions. Generic HTML uses fixed `/usr/bin/python3 -I` and the packaged reviewed stdlib parser, with bounded stdin/stdout/time, no arbitrary script or filesystem arguments. It produces source-token-tree locators, not browser DOM/computed visibility or semantic facts. Unsupported media/JSON, malformed HTML, byte/time failures and missing parsers remain explicit source gaps. No PDF parsing is claimed. All results remain unverified and nonpublishable; this is not ecosystem completeness or an article semantic-review adapter.

The evidence array contains actual private raw bytes in memory. There is no durable storage claim. A separate direct authorized Drive API archive, byte-readback receipt, content review, per-metric source policy, canonical history, release orchestration and approval are still required. Retrieval max ages are only retrieval bounds, never quote/chain/Morpho effective-value freshness approval. No generated claims or model calls occur. Later protected/private sources would require separately reviewed credentials and destination scope; this adapter has none.
