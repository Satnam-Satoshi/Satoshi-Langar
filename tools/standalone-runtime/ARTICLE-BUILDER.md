# Deterministic article preparation, no publication authority

`buildArticleDraft({now,registry,sourcePolicies,reviews,evidence,facts,stories,priorReview})` consumes independently authenticated structured inputs. No source fetch, model API, vendor SDK, filesystem write, rendering, PDF creation or publisher is implemented by this module. Exact byte hashes establish integrity, not truth. The caller must obtain semantic review and provenance independently, not manufacture a review map from generated assertions.

Registry entries are exact `{id,url,publisherId,parserId,parserVersion,metricKind}`. HTTPS URL identity is exact. Policies Map keyed sourceId includes sourceId,url,metricKind,kind(current/historical),maxAgeSeconds,expiresAt. Stricter policy expiry always applies; hard ceilings quote7200/Morpho900/chain1200/primary86400seconds cannot be relaxed. A historical record permits original day-only asOf precision and only retrieval freshness; current records require an exact asOf timestamp. Event dates remain the original dates or null, never replaced by retrieval time.

Fact exact keys: id,sourceId,sourceEventId,statement,eventAt,asOf,retrievedAt,kind,evidenceSha256,evidenceLocator,limitations. Statement/limitations are bounded inert plain text; markup/control characters hold. Null event means unknown, not now. Evidence locators are bounded evidence-relative paths, not external executable URLs. The evidence Map contains actual bytes keyedSHA256, with2MiB/source and16MiB aggregate cap. It stays private and is never returned with the draft.

Reviews Map keyed factId binds canonical articleFactSha256(fact), sourceId,url,publisherId,parserId,parserVersion,evidenceSha256,evidenceLocator,retrievedAt. The full fact digest includes statement, original dates and limitations. Unknown/expired/fabricated/mismatched references produce explicit story gaps; no fallback generated data or re-dating occurs. Duplicate fact/story IDs reject. Unassigned facts and every registered source remain accounted for; sourceCoverage is not an ecosystem-completeness claim.

Stories `{id,title,factIds}` specify only draft organization. Titles have unapproved-editorial-draft authority, not fact verification. No title or claim is auto-approved. All outputs remain publishable:false; zero accepted facts yields null expiry. Otherwise expiry is the earliest accepted fact policy deadline capped by five minutes.

Prior novelty review is independently supplied `{storyDigests:Map,sourceEventKeys:[]}`. Event keys are exact `articleEventKey(sourceId,eventId)` canonical JSON pairs, not delimiter-concatenated strings. Missing prior review means baseline-not-news. Identical facts mean unchanged; changed existing story means edited-existing-story; old known events recomposed are not new. Newly encountered events only become currentNewsCandidate when exact original event instants are within24hours; date-only/unknown/old events never infer current-news status. A candidate label still confers no factual or publication approval, and completeness/authenticity of the external prior inventory remains a caller obligation.

Optional `requestUntrustedArticleProse({draft,model,enabled:false,timeoutMs:10000})` invokes only an explicitly injected draft interface. No SDK or paid call is configured. Output accepts only bounded text and existing fact IDs; markup, invented references or extra authority fields hold. Even valid-looking prose is separately returned as untrusted and factualAccuracyEstablished:false; it is NEVER merged into facts or approvals. Source text is data, not instructions. A ten-second timeout requests cancellation and holds without retry; a model adapter must implement actual cancellation/accounting. Syntactic reference matching does not prevent fabricated claims in prose, so independent semantic review is mandatory before any later use.

Bounds:100sources,200facts,50stories,50factreferences/story,20limitations/fact, bounded canonical depth/nodes/bytes and model input128KiB/output12kcharacters. Synthetic tests only. No live model/source/API or authentication proof is claimed.

Storage preference: existing owner-paid Google Drive is the intended user-facing PDF/source/graphics/backup destination through a separately authorized DIRECT Drive API, independent of ChatGPT. This module does not require GCS or create an auth flow; Drive token scopes, ownership, exact byte readback and retention still require reviewed implementation. Transactional coordination remains a separate Firestore candidate, not a Drive-file lock. No credentials, billing changes or resources were created.

Model-attempt accounting: disabled returns modelRequestAttempted:false/modelOutcome:not-attempted. Once model.draft is invoked, every returned record reports modelRequestAttempted:true and modelOutcome:returned or unknown (throw/timeout). No effects:[] is returned after invocation. publicationExecuted:false is publication-specific, not a claim that a model transmission or charge did not occur. A timeout may have reached the provider and incurred cost; cancellation is best-effort and must not trigger blind retry. Preflight validation errors return held-model-preflight with modelRequestAttempted:false/modelOutcome:not-attempted before invoking the model.
