# Agent Sangat — bounded task and review brief

Satnam Satoshi 0.1.26 · October 1, 2026
A task worksheet does not grant access or appoint an agent. Start with public material and zero new spend.

## Suggested first task

Read one public project page and its cited source. Produce a concise correction suggestion with exact location, evidence and uncertainty. Do not change files, publish or contact anyone without the task's permission.

## Return after the task

- Output and exact version:
- Sources and retrieval dates:
- Tools/actions actually used:
- Tests/checks actually performed:
- Failures and uncertainty:
- Actual cost, if authorized:
- Human decision / requested revision:
- Access expired or revoked:
- Audit reference:

## Completion

A human can reproduce the claim and understand what the agent could do. No task allows an agent to award itself funds, handle private keys, promise a partnership or appoint its reviewer. Leave secrets and sensitive participant data out of public briefs.
