# Public roadmap: learn, create and serve

Planning revision: September 30, 2026. This expands the community front-door roadmap after founder feedback. Day 1 begins when the founder accepts the scope and appoints the first human owners. The 90-day sequence is a planning target, not a funded delivery promise. satnam.x publication remains deferred until the founder resumes it.

Start with the [ecosystem plan](docs/ECOSYSTEM-PLAN.md), [agent team](docs/AGENT-TEAM.md) and [community launch playbook](docs/COMMUNITY-LAUNCH-PLAYBOOK.md). Check [current status](docs/STATUS.md) for verified availability. Role names below are responsibilities to fill, not appointments.

## Release 0.1.26 — complete the next step

Langar, artists, meetup hosts, agent operators, collaborators, treasury researchers and mutual-aid researchers receive distinct planner paths. Before calling this release complete, verify the path selected in the browser matches the program, all toolkit downloads survive the production export, public GitHub drafts disclose visibility and user submission, and no screen implies a confirmed role, event, payout or accepted proposal. See the [flow map and toolkits](docs/ECOSYSTEM-PLAN.md#release-0126-a-complete-first-contribution-path).

This release improves participation today; the 90-day operational gates below remain in force. A working personal planner does not fill unassigned human roles or activate future services.

## Measures that tell us whether it helps

These are proposed review targets, not current results. Establish the baseline before comparing changes.

| Measure | First review target | How to avoid a misleading number |
|---|---|---|
| Onboarding | Five voluntary newcomer reviews; four find a suitable first action | Record friction and small sample size; do not imply a growth rate |
| Accessibility | Key journeys reviewed with keyboard, zoom and narrow screen | Link actual findings and unresolved limitations; [#48](https://github.com/Satnam-Satoshi/Satoshi-Langar/issues/48) |
| Learning | Six reviewed modules and feedback from five volunteer learners | Completion is optional; no public learner ranking |
| Publication | Three reviewed editions, then a seven-day rehearsal | Report missed days, data ages and corrections alongside output |
| Service | One approved cycle with minimal evidence and a human learning review | Do not publish recipient identity or invent meal counts |
| Agent usefulness | Accepted deliverables, human review time, cost and correction rate | Do not use agent count, messages or tokens as impact |
| Continuity | One independently performed restore and access-revocation exercise | Preserve what failed and how it was repaired |
| Payments, if separately activated | Reconciled receipts, exceptions and incident handling | Distinguish donations, artist revenue, expenses and balances |
