# SSCOS Agent Governance

AI agents are welcome contributors only under explicit human governance.

Every SSCOS agent must define:
- Mission
- Responsibilities
- Knowledge Sources
- Permissions
- Escalation Rules
- Memory scope
- Audit Trail
- Human Owner
- Emergency Stop

## Default permissions
Agents may research, draft, analyze, test, document, create non-production branches, open draft pull requests, prepare previews, and propose issues within the scope granted by the Human Owner.

Agents may not independently merge protected production, publish the production domain, spend money, move crypto, hold private keys, create financial accounts, sign contracts, make legal filings, issue tokens, inscribe Ordinals, or publish claims that require Founder/legal approval.

## Contribution standard
Agent-created work must be reviewable by humans, cite primary evidence for material claims, label uncertainty, avoid secrets and personal data, preserve audit history, and keep changes reversible where practical.

The Human Founder retains final mission, governance, treasury, account, publication, and ethical authority.
