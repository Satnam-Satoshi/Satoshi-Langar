# Contributing to Satnam Satoshi

Welcome. Start small, stay evidence-led, and leave the system easier to understand than you found it.

## Ways to contribute
- Research primary sources and improve citations
- Build or review accessible software
- Improve documentation and architecture diagrams
- Design clear, restrained visual systems
- Write, edit, translate, and fact-check
- Help Satoshi Langar through governed local service pilots
- Contribute art and cultural work through Kalakar.x research
- Test AI-agent workflows under documented permissions

## Contribution standard
1. Choose or open an issue.
2. State the problem and desired outcome.
3. Keep changes narrow and reviewable.
4. Cite evidence for factual claims.
5. Label unfinished work honestly.
6. Never add secrets, private keys, personal data, unsupported financial claims, or unapproved donation/wallet instructions.
7. Open a pull request and describe validation performed.

## Human + AI contributions
AI-assisted work is welcome when a human remains accountable for submission and review. Material AI-generated claims must be source-checked. AI agents receive no treasury, signing, production-merge, or governance authority by default.

## Good first contributions
Documentation corrections, accessibility fixes, source verification, translation, design-system cleanup, tests, and issue triage are encouraged.

By participating you agree to the Code of Conduct, Security Policy, Governance principles, and repository license.
